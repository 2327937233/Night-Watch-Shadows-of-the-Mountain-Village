# 《守夜：山村旧影》Art Bible v0.1

状态：阶段2规范草案，基于 2026-09-08 实测。以下数值是试调起点及目标，不代表已全部应用。

## 视觉识别

潮湿雨夜的旧宅，昏黄方灯连接路径，手电揭露材质，祭祀痕迹在探索中渐渐出现。恐怖来自有结构的暗部、封闭空间与未解释的生活残留，不来自血迹、鬼脸或整体滤镜。

保留地图、角色当前站位、镜头逻辑和功能。中央通道净空，两侧道具偏功能性；远端门与室内供桌分别担当焦点。建筑为大形，门窗/家具为中形，纸灰/裂痕为小形；先解决大中形再加小形。

## 材质库（渐进映射，不全局强行替换）

## 建筑与模块

沿现有位置逐项抽出 Wall/Column/Door/Window/Roof/Lantern/Stair/Prop 的可复用构建接口或场景，不一次重构全部生成器。统一材质引用、尺度、碰撞职责与灯源预算。

- 左一完整、左二更潮闭塞；右一生活遗留、右二封闭。差异来自门窗、污迹、道具与照明，不镜像复制。
- 主门保留完整围合，门洞凹入、框厚约 .15–.30m、门板厚约 .05–.10m；3–4级宽石阶接平台。中轴少杂物。
- 屋顶必须读到檐口/椽子/瓦面三层；反光只出现在合理朝向，局部错瓦不大塌。
- 墙体实体封闭。增加细节时同步检查胶囊通行、台阶与接触阴影，不改变控制器来掩盖模型问题。

## 灯笼与灯光

同系列旧方形木框纸灯：四面有木架、纸有内缩与厚度、挂件接梁，向院面可读木格。2200–2700K视觉暖感，约2–4m局部范围；不要直接把色温或功率等同于某固定 energy。

光源职责：手电揭露细节，灯笼/烛光指引目标，弱冷环境光只分离大形。先减过强发光和无来源补光，再调整边缘层次。门中央与门缝保持深暗，不做均匀正面照明。

阴影预算先做试验：室内保留手电和供桌关键烛光阴影，其余以无阴影/自发光处理；庭院按当前可见范围选择关键灯。必须检查漏光后再接受预算，不能为减灯制造穿墙光。实际帧时间决定最后预算。

## 祭祀厢房

入口冷光 → 中段零散生活/祭祀痕迹 → 暖光供桌。保留中央路，家具靠墙有缘由。地砖不宽缝棋盘化，供桌抬高不破坏脚底定位。

供桌有厚桌面、腿、牙板；中央最大木牌「王氏先祖之位」，两侧较小「王氏宗亲之灵位」「王氏历代先人神位」。文字是旧黄金漆，不做发光标牌。铜/陶香炉、2–4线香、残灰、供盘、茶盏、少量旧纸；家谱为线装书，不只有一块标题板。

蜡烛有蜡体、蜡泪、灯芯与软火焰。烟是细密度柔边粒子，有生命周期淡出，禁用无遮罩方片。布幔破旧但不铺满鲜红色。

## 天气、角色与声音

保留已有三层雨，先校验可见范围与屋檐遮挡；室内不生成雨。屋檐滴水、水花分区少量添加。薄雾只分离远近，近景材质保持清晰。

保留 2.5D 角色与控制接口；视觉层独立处理边缘、色彩与接触阴影，不为美术重写移动。手电逐方向/步态标定右手灯头，目标范围8–14m、角度28–38°为试调参考；先比对实际画面，不能盲改数值。步行摆动克制。

雨声强于脚步但不可掩掉反馈。室内雨声减弱、声音更封闭；步频跟实际位移，撞墙不持续踩踏。音频需听测，不把 dB 参数检查当作混音完成。

## UI与物品页

## 性能、验收与修改纪律

重复砖瓦优先共享Mesh/材质或MultiMesh，细碎草不逐节点；按区域合并，不把整院合成一个无法剔除的大物体。静态遮挡/LOD先做功能和GPU成本对比；无证据不宣称已优化性能。

每模块记录：问题 → 限定文件/范围 → 前后同机位图 → 视觉差异 → 灯/网格统计 → 功能回归 → 遗留项。顺序按用户阶段执行，不跨模块堆改。

视觉验收：第一眼读结构、第二眼读材质、第三眼读叙事。功能回归：移动/碰撞/台阶/手电/脚步/E交互/钥匙门锁/Tab背包/ESC返回。未测试项明确标注，不能以“脚本运行无错”代替验收。
