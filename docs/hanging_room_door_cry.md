# 终章第二部分：门后的哭声

沿潮湿脚印回到吊绳房。等陈默说完“她为什么一定要让我回来？”，走到旧木凳附近。门合拢后，留意门内侧的求救声和三下敲门。随后回到门前，按 **E** 查看门板和门框，再按 **E** 开门。走到门槛按 **E** 返回正堂，在同一扇门外按 **E** 调查旧门闩。最后一声抽泣消失后，雨声恢复，任务更新为“还原当年的真相”。

演出中可以走动、使用手电。门向外摆动，不扫入玩家通行区。演出和调查的短暂对白期间会屏蔽重复交互；如果用 ESC 提前离开，回来后可从调查房门继续。进度由现有 GameState 保存于本次游玩，随新游戏重置。

音轨存放于 `assets/audio/door_cry/`：

| 轨道 | 搭配与配音方向 |
| --- | --- |
| `yuelan_*.wav` | 沈月兰的三句求救。由房门内侧发出，轻微木屋回响。正式录音时用年轻女声，第一句短而弱；第二句在“求求你们”后换气；“我没有疯”应带哭腔，像在努力让门外的人听清。 |
| `chen_*.wav` | 陈默的低声对白。近声，少回响；先迟疑，再把供词与门闩联系起来。结尾两句之间留一口气。 |
| `sob_*.wav` | 公开版在 `assets/audio/public_effects/` 提供三个合成抽泣片段。门外调查结束后的抽泣最轻，从门内发出。 |
| `hinge_*.wav`、`door_seat.wav`、`knock_*.wav` | 公开版的门轴和合拢声使用 `public_effects/` 的合成音效。三声闷木敲击保留原设计，分别是轻、稍急、最后转弱；不加配乐。 |

对白是本机普通话合成的可替换音轨。真人录音建议保留同名、单声道 WAV；门口回响可在沈月兰音轨中轻加，陈默音轨保持干声。脚本会按音轨长度保留字幕并顺序播放。

调查完外侧门闩后，从同一扇门回到西厢，进入[终章第三部分：还原当年的真相](hanging_room_reconstruction.md)。
