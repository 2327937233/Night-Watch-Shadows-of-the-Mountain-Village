# 沿脚印返回吊绳房：调查段

沿用 `HangingSideRoom.tscn`，不新增地图、角色、通道或家具。新控制节点由
`hanging_room_return_investigation.gd` 管理，原房间继续负责移动、手电、ESC 和 E 输入。

## 触发与顺序

原脚印系统已经激活，且玩家进入既有吊绳房时启用。本段不会在第一次进入房间时出现。
正堂脚步、哭声和门口抽泣均属于正堂场景，切换时停止。本段不创建持续行走的女人音源。

1. 入场压低雨声，留约 1.6 秒安静，再依次显示“脚印到这里就没了……”和
   “她为什么一定要让我回来？”，任务为“调查吊绳房的异常”。
2. 入场对白播完后，靠近原木凳触发[终章第二部分：门后的哭声](hanging_room_door_cry.md)。
3. 查完旧门闩并再次进屋后，开始[终章第三部分：还原当年的真相](hanging_room_reconstruction.md)。

旁白沿用项目现有字幕系统，不加入额外 UI。分段期间限制重复 E 和打开新文件，
正常移动、第三人称镜头、手电开关、ESC 返回仍然可用。

## 环境

- 原吊绳父节点继续使用，缓慢摆动不超过约 1 度。
- 原木凳仅偏移 `(0.10, 0, -0.06)` 米，原有子碰撞跟随；每次加载从原位应用一次。
- 四条细小拖痕直接加入既有地砖材质，沿用砖面法线/砖缝，不增加贴片或碰撞。
- 两支原蜡烛火焰全部隐藏，灯光和闪烁缓存同步置零，避免下一帧重新点亮。
- 所有原香火余烬隐藏；香炉烟停止发射并隐藏已存活烟粒子，香炉与香枝保留。
- 原暖色吊绳聚光关闭，冷色结构辅助光、玩家手电保留。
- 既有符纸、纸钱和少量轻微纸张飘动保留，不重新散布。

## 状态与取消

`GameState` 保存 `hanging_return_entry_complete`，新游戏重置。重新进入后，
完成的入场对白不重播，熄灭的蜡烛、香火和木凳位移仍然生效。入场对白未完成就离开时，下次进入仍可看到完整对白。

## 验证

`tmp/validate_hanging_return.gd` 检查入场静默、字幕、环境、重载、手电与移动。
门板、门闩及门内音效由 `tmp/validate_hanging_door_story.gd` 覆盖。
