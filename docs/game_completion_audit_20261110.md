# 《守夜：山村旧影》完工验收

验收对象：当前 Godot 4.7.1 工作区及已有的 Windows 资源包。结论：**主线内容完成，可作为可玩测试版；正式发布验收未完成。**

| 范围 | 验收结果 |
|---|---|
| 主线 | 分段实际运行宅外开局、左厢钥匙、正堂、书房、卧房身份确认、供词、哭声与沈月兰背影、脚印返回西厢、房门和门闩、证据还原、告别、从原宅门离开、结局和返回菜单。部分自动用例直接设置前置状态；没有把它当作一轮不看攻略、不注入状态的限时通关。 |
| 计时、失败、重试 | 05:59 锁定移动的告别段停表；05:59 宅门提交成功；06:00 进入失败，禁止触发宅门离开。失败重试和回菜单均可用。失败雷声、哭声和正堂追踪音效在自动音频采样中有实际信号。 |
| 文档和背包 | 8 份文档在三种视口尺寸下内容完整；通过信件和供词的阅读门槛、旧照片累计点击、字幕保护、背包翻页和银簪合并测试。 |
| 地图与交互 | 主要区域载入成功，庭院与左厢碰撞、脚印路线实际移动、卧房返回和终章出口均检查。扫过运行脚本、场景、材质、着色器中的固定资源路径，未发现缺失文件。 |
| 美术与性能 | RTX 5060、1600×900、Forward+ 采样 11 个场景视角及四张 UI 截图。房间分区、正堂烛光和文件正文清楚；庭院右廊与部分暗部在缩图中仍难辨。庭院入口约 2719 次绘制，高于本次其他视角，低配稳定性尚无结论。 |
| 存档与设置 | 720p 原生窗口检查了设置，并跨进程验证「继续游戏」。念名后和重返西厢后的检查点可用；告别后退出仍会回退到重返西厢检查点，已通过独立用例复现。 |
| Windows | 当前 PCK 从空目录由 Godot 加载成功；重新尝试导出独立 EXE，仍缺 Windows x64 4.7.1.stable 模板，本次未产生可直接分发的 EXE。 |

发布前按顺序处理：

1. 配齐 Windows 导出模板，生成独立包；在无编辑器的机器上验证字体、音频、失败重试和完整结局。并核实游戏内实际使用的外部哭声、脚步等素材的发行许可，缺少凭据的素材先替换。源工作区有一份木门音的使用授权记录，不能据此覆盖其他素材或发行用途。
2. 在沈月兰告别结束、玩家恢复操作时保存「带着真相离开王宅」检查点，读取后应保留落地麻绳、香炉复烟和背包供词，且不重播门后事件与告别。若希望菜单保留通关记录，通关标记应和本轮检查点分开；当前结束只清除检查点。
3. 安排首次玩家不看攻略，从新游戏开始用原速时钟走完一轮；另做低配实机、耳机混音和连续切场检查。部分运行测试退出时仍报对象或资源释放警告，目前没有足够证据判定正常游玩持续泄漏。

本轮只更新测试和验收记录，未改动正式玩法。测试输出和场景截图在 `tmp/completion_audit/`，独立存档复现用例为 `tmp/validate_completion_checkpoints.gd`。
