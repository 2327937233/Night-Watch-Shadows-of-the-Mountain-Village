# 终章第三部分：还原当年的真相

查完正堂回廊侧的旧门闩后，回到原有西厢房门，按 **E** 推门返回。陈默的两句入场对白结束后，可以先检查房梁麻绳，也可以先调查旧木凳。

- 麻绳调查检查纤维、绳结和固定处磨损。若持有「旧麻绳残段」，追加粗细和编织方式对照，不据此认定出自同一根绳子。
- 木凳保留原模型、碰撞、位移和砖面拖痕。腿脚的磨损和凳面的积灰使用原网格的材质叠层。
- 两项都完成后，底部字幕短暂摘录已读供词，再由陈默串联门闩、绳子、凳子和王家的说法。供词始终留在原背包。
- 房梁附近最后一次抽泣约 2.56 秒，结束后原麻绳逐渐停下。陈默回应后留两秒安静，任务改为「在吊绳下留下真相」。
- 最终提示位于原木凳左侧，避开吊绳正下方。**本阶段仅解锁「放下王承安的供词」，按 E 不消耗供词、不启动结局。**

陈默的可替换普通话合成音轨在 `assets/audio/hanging_truth/`。公开版使用 `assets/audio/public_effects/beam_sob.wav` 的合成抽泣，经房梁处的 3D 音源播放。场景间进度沿用 GameState：保留已完成的调查与回顾进度，播放过的最后一次抽泣不会重播。重新开始游戏会重置这些状态。
