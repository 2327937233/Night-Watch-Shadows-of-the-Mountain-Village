# 《守夜：山村旧影》当前版本复查

检查日期：2026-11-09。覆盖宅外、庭院、左侧厢房、王氏正堂、书房、封镜旧卧房、吊绳房，以及成功离开和 06:00 失败两条结局。此次只复查与记录，没有改动正式游戏脚本、地图、音效或 UI。

## 建议先修

| 优先级 | 实测结果 | 建议 |
|---|---|---|
| 已修复（原 P1） | **05:59 交互离开曾在过场中失败。** 原判定以角色跨过门槛为准，但那时出门过场已经接管移动并隐藏时钟。 | 现在以解锁后的宅门有效交互为准，按 E 即停表；如果已到 06:00，仍判失败。 |
| P1 | **八分钟硬时限没有可恢复的进度。** 每个有效游戏秒推进一分钟，22:00 到 06:00 为 480 秒。背包和阅读会暂停，但放下供词后的过场本身约 51 秒，仍扣时间。重试从开头开始；退出进程没有“继续游戏”。 | 保留时钟倍率及 06:00 失败。强制、不可操作的演出用独立的停表机制；用开局一句说明和 05:30 的一次低调提醒告知时限。为终章等安全节点提供继续功能，确保失败重试不会读回已经超时的状态。 |
| 已修复（原 P1） | **失败后正堂脚步曾继续推进。** 供词熄灯后、第一声脚步前触发 06:00，原本会在暂停后执行三次脚步播放调用。 | 正堂延时随场景暂停；06:00 同步取消脚步、哭声和混响，冻结相关动画。复测脚步计数保持为 0，已经响起的引导哭声立即停止。 |
| P2 | **两封信可在没看完时推进。** 在 1280×720 的布局中，《未寄出的信》和《旧仆信》都是两页。只关闭第一页，卧房已记录读过，书房已让远门虚掩、钥匙显示；阅读器本身均未记录完成。 | 沿用供词的末页判定，分别记录“已取得”和“读完”，从背包继续读也可推进。 |
| P2 | **身份题记容易漏掉。** 旧照片点两次、关闭、重开再点一次，计数为 1，题记不出现；同次展开连点三次可触发。照片题记又是身份链的一环。 | 跨开合保留检查次数。用照片翘起的角或弱提示“再查看背面”给出反馈，保留手动检查的探索感。 |
| P2 | **回庭院会显示旧任务，还可能把玩家放回入口。** 正堂已经是“调查王氏正堂”，主屋也已解锁，返回庭院仍显示“进入荒宅主屋”。非结局回退走默认庭院出生点，结局回退才复用主屋门边出生点。 | 将出生点与实际来向关联；让剧情状态决定右上角任务，门边提示只描述当地交互。统一“正堂／祠堂”的叫法。 |

## 美术与声音

- **庭院：** 近处灯笼比远端主屋更抢眼，右侧檐口和柱廊几乎并成一片。建议只补低强度的冷色边光，提高入口和廊柱辨识度，保留雨夜的明暗对比。
- **正堂、书房、卧房、吊绳房：** 现有布局和动线足够。按玩家最近观察距离精修供台木作、牌位与香炉；书房优先线装书书口、家谱、桌沿；卧房优先床幔、镜布垂坠与床架接合；吊绳房优先麻绳捻股与受潮细节、木凳磨损。先做剧情视线上的道具。
- **镜头与角色：** 前景木柱会遮住陈默；可测试小幅镜头避让或只淡化挡在角色和镜头之间的柱体。人物在黑暗中的高光和地面照明略有脱节，可补随局部光线变化的角色明度与接触阴影。
- **HUD 与可访问性：** 红绿条和脉搏图目前未检索到完整玩法对应，可简化或说明。建议提供雷声／音效音量和减少闪光选项；对比 720p、1080p、1440p 的字幕与题记可读性。结局照片背面的婚期文字可稍加大或延长停留。
- **混音：** 失败雷声与哭声均捕获到实际音频输出。正堂脚步、门后敲击与终章告别也通过各自回归。建议按环境音、剧情音效、对白统一分组，再用耳机实际核对方向和响度；不要把可播放等同于听感已经合适。
