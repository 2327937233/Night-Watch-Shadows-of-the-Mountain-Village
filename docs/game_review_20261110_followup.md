# 《守夜：山村旧影》巡检修复记录

对应《当前版本复查》，按优先级处理。未调整地图布局和任务顺序。

| 优先级 | 修改 | 验收 |
|---|---|---|
| P1 | 强制锁住移动的剧情段落暂停倒计时，恢复控制后续算。卧房念名在失败时取消尚未执行的延时、音源和任务更新。 | 05:59 开始告别能够播完；恢复控制仍是 05:59，下一分钟正常失败。卧房自然超时后字幕、脚步和任务保持不变。宅门仍可在 05:59 提交离开。 |
| P1 | 开局说明规则，05:30 起时钟旁保留离开提醒。在念名事件完成、重返西厢演出完成后写入检查点。 | 失败可重试，重启程序也可从菜单继续；检查点恢复场景、物品、文件阅读、调查进度、手电与时钟，最少留 90 个可操作秒。无检查点时仍从宅外开局。 |
| P2 | 旧合影点击跨开合累计；卧房提示指出缺少的调查，正堂仍要求确认完整姓名。 | 点两次、关闭、重开再点一次显示题记；读过照片不等于确认完整姓名。 |
| P2 | 正堂回庭院在主屋门前落脚，左厢返回时在厢房侧。各场景复用全局任务状态，正堂导航用同一个称呼。 | 退回庭院不丢任务；验证门槛、拐角、碰撞和脚印路线。 |
| P2 | 合并庭院重复檐口、椽木和屋瓦的五组绘制，只关闭两盏辅助灯的阴影，并给右回廊补弱冷光。 | 1600×900、Forward+、RTX 5060 的入口视角，平均绘制调用 3069 → 2719（约少 11.4%），阴影灯 8 → 6；地面碰撞数量保持在大门修订后的 116。未测低配帧率。 |
| P2 | 增加 Windows x86_64 预设与图标，排除测试、文档和未用原始素材；改用系统楷体和中文回退字体。 | 资源包可在空目录由 Godot 加载至主菜单；独立 EXE 仍需要 4.7.1.stable Windows 导出模板。 |
| P3 | 手电开关跨场景保留；修复庭院快速切离时的延迟重建；隐藏没有玩法含义的状态条；增加可记忆的环境音、雷声和减少闪光设置。 | 720p 原生窗口检查了设置页和中文字体；跨进程恢复设置，通过快速切离庭院、手电跨场景、背包和文件分页测试。 |

发布前还需核实项目内正在使用的外部脚步、哭声等素材的发行许可。楷体文件保留在源工作区供溯源，运行时不再引用，导出预设排除该文件。建议在另一台 Windows 机器上检查字体回退和声音，并从生成的 EXE 分别验证超时、继续和成功离开。

测试输出在 `tmp/followup_20261110/`。场景截图在该目录的 `native/`。部分测试进程退出仍有对象或渲染资源的释放警告，尚未验证正常游玩是否持续增长；场景家具细化、低配性能和耳机空间混音属于后续实机打磨。
